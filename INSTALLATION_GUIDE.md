# Vanilla Retail — Windows Application Installers & Setup Guide

This folder contains standard Windows `.exe` Setup Installers for both **Vanilla Retail POS Cashier** and **Vanilla Retail Operations Center**.

---

## 📦 Installer Files

1. **`VanillaRetail-Cashier-Setup.exe`**
   - Windows Installer for the **POS Cashier Application**.
2. **`VanillaRetail-OperationsCenter-Setup.exe`**
   - Windows Installer for the **Operations Center (Manager) Application**.

---

## 🚀 Setup & Installation Instructions

### Step 1: Install the POS Cashier Application
1. Double-click **`VanillaRetail-Cashier-Setup.exe`**.
2. Follow the standard Windows Installation Wizard prompt.
3. (Optional) Check **"Create a desktop shortcut"**.
4. Click **Install**, then click **Finish** to launch the application.

### Step 2: Install the Operations Center Application
1. Double-click **`VanillaRetail-OperationsCenter-Setup.exe`**.
2. Follow the standard Windows Installation Wizard prompt.
3. (Optional) Check **"Create a desktop shortcut"**.
4. Click **Install**, then click **Finish** to launch the application.

## 🗑️ How to Uninstall Anytime

Both applications register natively with Windows **Add or Remove Programs / Installed Apps**.

To uninstall at any time:
1. Open Windows **Settings** (`Win + I`) -> **Apps** -> **Installed apps** *(or Control Panel -> Programs and Features)*.
2. Search for **"Vanilla Retail"**.
3. Select **Vanilla Retail POS Cashier** or **Vanilla Retail Operations Center** and click **Uninstall**.
4. The uninstaller will cleanly remove all application binaries, shortcuts, and registry entries.
